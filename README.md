# Noct · 守夜

Noct 是一款暗夜童话风格的 2D 俯视角探索战斗 + 轻度家园经营原型。玩家扮演蓝色小狐狸 Noct，在月光区域中自动攻击、走位、收集资源并选择撤离，随后回到家园种植、收获和建设。

当前导出版本：`0.10.0`  
源码基准：`df5d45c`  
线上试玩：<https://noct-lantern.pxf-1296344483.chatgpt.site>

## 1. 当前游戏状态

这是一个可继续开发的网页游戏原型，不是单文件演示。项目使用原生 JavaScript、HTML、CSS 和 Canvas 2D，没有使用 Phaser、Vite 或 TypeScript。

- 游戏逻辑画布：640 × 400。
- Noct 单帧画布：64 × 64；四方向行走图集：256 × 192。
- 探索世界坐标：2048 × 1280；当前地图美术原稿：1586 × 992。
- 生产部署：Cloudflare Worker 风格入口 + R2 账号存档。
- 本地开发：Node.js 静态服务器 + 本地 JSON 存档，不依赖线上账号。
- 游戏代码目前位于 `dist/`。这是现有项目结构的一部分，不代表只有编译产物。

## 2. 已实现功能

### 角色与战斗

- Noct 四方向行走；向左使用右侧动画镜像。
- 正面站立、呼吸、眨眼、耳朵和尾巴轻微待机动画。
- 停步后平滑恢复正面站立。
- WASD、方向键和触屏拖动移动。
- 自动攻击、敌人追踪、生命值、经验、升级与资源掉落。
- 伤害、攻速、移速、拾取范围、生命和环绕鬼火升级。
- 暂停菜单显示实时属性、Build、家园加成和背包材料。

### 四张探索地图

- 月影森林。
- 荧光湿地。
- 星落雪原。
- 灰烬峡谷。
- 家园入口可选择出发区域。
- 640 × 400 跟随镜头、小型方位图、地形碰撞、可达资源点和敌人绕行。
- 3 分钟时选择撤离或继续，最长探索 4 分钟。
- 草木、水面、冰面、熔岩、发光物和少量粒子的轻微环境动态。
- 暂停时环境动画冻结；暂停菜单可关闭环境微动态；尊重系统“减少动态”设置。

### 家园与存档

- 可行走的林间家园。
- 月光萝卜和星铃花的播种、成长与收获。
- 小屋、工作台、菜地和休息花园建设。
- 暖汤与永久家园加成。
- 探索结算后推进作物成长，死亡或提前撤离仍保留已拾取材料。
- 线上按登录账号保存；本地开发使用 `.local-data/home-saves.json`。
- ETag 冲突保护、无效存档校验和跨来源写入保护。

## 3. 项目结构

```text
Noct/
├── .openai/hosting.json     # 当前 Sites/Worker 部署配置
├── art/                     # 原始美术、设计说明和资源处理脚本
│   ├── maps/                # 四张地图 PNG 原稿
│   ├── CHARACTER.md         # 角色美术说明
│   ├── HOME.md              # 家园美术说明
│   └── AMBIENT-MAPS.md      # 地图环境动态与 Godot/Unity 移植说明
├── dist/                    # 当前游戏源码与运行资源
│   ├── index.html
│   ├── style.css
│   ├── game.js              # 核心战斗与角色动画
│   ├── home.js              # 家园、种植、结算和属性面板
│   ├── exploration.js       # 四地图、碰撞、寻路和环境动态
│   ├── maps/                # 游戏运行使用的 WebP 地图
│   └── *.png                # Sprite、家园、作物及其他资源
├── tests/home-flow.cjs      # 家园、存档、四地图和结算流程测试
├── dev.mjs                  # 本地开发服务器与本地存档适配器
├── server.mjs               # 生产 Worker 与账号存档 API
├── build.mjs                # 生成生产 Worker
├── package.json
└── package-lock.json
```

`dist/server/`、`dist/.openai/` 是 `npm run build` 生成的部署产物，因此不放入导出包；项目根目录的 `.openai/hosting.json` 会保留。`node_modules/`、`.sites-runtime/`、`.local-data/`、Git 历史和系统缓存不会进入压缩包。

## 4. 如何启动

### 环境要求

- Node.js 20 或更高版本。
- npm 10 或兼容版本。

### 本地运行

```bash
npm install
npm run dev
```

浏览器打开：<http://localhost:4173>

本地服务器会提供完整游戏和 `/api/home` 存档接口。存档写入 `.local-data/home-saves.json`，该目录已被 Git 忽略。按 `Ctrl + C` 停止服务器。

如 4173 端口被占用：

```bash
PORT=4174 npm run dev
```

### 测试

```bash
npm test
```

测试涵盖家园启动、移动、种植、成长、收获、建造、暖汤、所有局内升级、存档冲突与隔离、四地图选择、边界与碰撞、资源可达性、刷怪、环境动画开关、3 分钟撤离和 4 分钟结算。测试截图默认写入系统临时目录；可用 `NOCT_TEST_OUTPUT` 指定位置。

### 生成生产版本

```bash
npm run build
```

这会生成 `dist/server/index.js` 和 `dist/.openai/hosting.json`。生产环境需要与 `.openai/hosting.json` 对应的 R2 绑定 `BUCKET`；本地开发不需要配置 R2。

### 重新处理美术资源

只有修改原始美术后才需要运行：

```bash
npm run prepare:home
npm run prepare:maps
```

地图 PNG 原稿会保留在 `art/maps/`，运行时 WebP 位于 `dist/maps/`。

## 5. 下一步计划

1. 将树木、遗迹、岩壁拆成地面层、碰撞层和前景遮挡层。
2. 使用角色脚底坐标进行 Y 排序，解决狐狸或敌人看起来站在树冠上的问题。

4. 扩展地图敌人、资源路线、精英怪和随机事件。
5. 加入食物选择、探险目标和更完整的 3 分钟撤离风险收益。
6. 完善音效、背景音乐、移动端性能和触屏操作。
7. 待玩法稳定后再评估迁移 Godot/Unity，当前实现说明见 `art/AMBIENT-MAPS.md`。

## 已知限制

- 四张探索地图目前是合并底图，树冠、树干和地面没有完全拆层，因此前后遮挡仍需下一阶段处理。
- 当前环境动画通过局部遮罩作用于合并底图，适合原型，但不等于完整 Sprite 分层动画。
- 本地存档与线上账号存档相互独立。
- 测试可以验证逻辑和 Canvas 渲染，但不能代替真实手机的性能测试。
