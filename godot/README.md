# Noct · 守夜：Godot 4 移植

这是与现有 `dist/` 网页版并存的 Godot 4.7 迁移分支。第一阶段不是重写全部玩法，而是先解决地图结构问题：整图底图、粗略碰撞和角色总在树冠上方。

## 当前可运行内容

- 四张探索地图，按 `1`–`4` 切换。
- Noct 四方向移动动画。
- 独立于贴图的 `StaticBody2D + CollisionPolygon2D` 碰撞。
- 角色只用脚底小胶囊参与地形碰撞，不再用整张角色图片判断。
- 月影森林、荧光湿地的树冠采样遮挡：角色走到树后时树冠覆盖角色，走到树前时角色覆盖树冠。
- `F2` 显示/隐藏碰撞调试：红色为实体碰撞，蓝色为前景遮挡。
- `R` 把角色重置到安全出生点。

## 启动

在仓库根目录执行：

```bash
/path/to/Godot --editor --path .
```

或直接运行：

```bash
/path/to/Godot --path .
```

## 如何重新设置地图碰撞

所有碰撞数据位于 `godot/scripts/map_definitions.gd`，使用原始地图的 `640 × 400` 参考坐标：

- `oval(center, radius)`：适合树根、岩石和晶簇。
- `polygon([...])`：适合河岸、岩壁、熔岩和不规则障碍。
- `occluder(rect, foot_y)`：从原始地图采样一块前景；`foot_y` 决定角色何时在它前方或后方。

修改数值后重新运行即可。编辑时保持 `F2` 开启，红色区域应只覆盖真正不能站立的树根、岩石或水域；树冠应使用蓝色遮挡区域，而不是全部设为实体碰撞。
